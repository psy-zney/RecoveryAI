# resc launch notes (draft)

Before publishing an announcement, verify release assets, npm availability, and [implemented capabilities](engine-capabilities.md). Physical-device support is Windows-only, raw-device exports are unavailable, and software read-only access is not a hardware write blocker.

Repository: https://github.com/psy-zney/resc

Suggested description: resc is a Rust MCP server for disk-image forensics, signature scanning, and virtual copy-on-write recovery experiments. It includes Windows physical-drive inspection and synthetic image tests.

The README demo is an illustration, not a recording of an actual recovery. Avoid claims of unmeasured performance or unsupported recovery features.
